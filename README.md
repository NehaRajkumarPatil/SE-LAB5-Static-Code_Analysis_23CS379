## 🎯 Objective
To improve code quality, readability, and security by performing **Static Code Analysis** on `inventory_system.py` using three tools:
- **Pylint** → Code quality and logic issues  
- **Bandit** → Security vulnerabilities  
- **Flake8** → PEP8 style and formatting compliance  

---

## 🧠 Learning Outcomes
- Identified and fixed logical, security, and style issues using automated tools.  
- Understood the importance of static analysis in improving maintainability.  
- Achieved a **Pylint score of 10/10** and no issues in Bandit or Flake8.
